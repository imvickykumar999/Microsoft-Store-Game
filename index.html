// STEP 01 & 02: DUAL TRACK FLOW

Host a Match or Join Your Friends

Follow the corresponding track below. Executables are located in the play/ folder of this repository.

Host Setup (Leader)

SERVER ROLE
  1. 1
    Connect to Tailscale

    Ensure your Tailscale client is signed in and says Connected in your Windows taskbar tray or macOS menu bar.

  2. 2
    Invite or Share with Friends

    Send a machine share invite from your Tailscale Admin Console, or share your reusable invite link privately.

  3. 3
    Launch play/server.exe

    Double-click server.exe. A terminal opens and auto-detects your Tailscale IPv4 address:

    [*] Server listening on 0.0.0.0:8888
    [*] Tailscale IP = 100.121.132.98 (Share with friends!)
    [*] Local LAN IP = 192.168.1.5 (Wi-Fi only)
  4. 4
    Keep Server Running & Share IP

    Keep the black terminal window open. Copy your 100.x.y.z Tailscale IP and send it to your friends!

Player Setup (Joiner)

CLIENT ROLE
  1. 1
    Accept Invite & Launch Tailscale

    Open the invite link from the host in your browser, accept the connection, and ensure your Tailscale desktop app is running and Connected.

  2. 2
    Launch play/client.exe

    Run client.exe from the play/ folder. The high-tech launcher configuration GUI will appear on screen.

  3. 3
    Enter Host Tailscale IP

    Type the host's 100.x.y.z address into the Server Address box. Keep port at 8888.

  4. 4
    Select Name/Color & Click Play

    Pick your battle username and avatar color (Red, Blue, Green, Gold, etc.). Press Play or hit ENTER to drop into the 3D deathmatch arena!

Troubleshooting & Fixes

				
Quick solutions to common connection, firewall, and peer handshake roadblocks.

			


			
			

				

					FIND YOUR TAILSCALE IP
					

						tailscale ip -4
						
					

				


				

					CHECK ONLINE PEERS
					

						tailscale status
						
					

				


				

					ALLOW TCP PORT 8888
					

						netstat -ano | findstr :8888
						
					

				

			


			

				

					
					

						
    
							
  1. Verify that server.exe is already running on the host machine before the player clicks Play.
    2. 
							
  2. Double-check that the IP entered into the client begins with 100. (e.g. 100.121.132.98), not 192.168.x.x or 127.0.0.1 unless testing locally on the same PC.
    3. 
							
  3. Verify port 8888 is specified without spaces or typos.
    4. 
						

					

				


				

					
					

						
Run tailscale ping <host-tailscale-ip> in PowerShell or Terminal. If packets drop:

						
    
							
  • Check the Tailscale tray icon on both machines; both must display Connected.
    • 
							
  • If using node sharing, confirm in the Tailscale admin console that the guest accepted the invite.
    • 
							
  • Temporarily disable third-party antivirus firewalls that may block virtual network adapters.
    • 
						

					

				


				

					
					

						
If Windows blocks inbound connections on port 8888, open PowerShell as Administrator and run:

						

							New-NetFirewallRule -DisplayName "Ursina TCP 8888" -Direction Inbound -LocalPort 8888 -Protocol TCP -Action Allow
							
						

					

				


				

					
					

						
If all computers are plugged into or connected to the exact same home router Wi-Fi:

						
    
							
  • The host starts server.exe and notes the Local LAN IP (e.g. 192.168.1.5).
    • 
							
  • Players enter that 192.168.x.x address into client.exe and click Play.
    • 
							
  • Ensure Windows Firewall is set to "Private Network" on all machines.
    •
